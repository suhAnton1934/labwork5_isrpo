# Документация проекта

## 1. Общее описание решения

Данный проект представляет собой программу на языке программирования Python,представляющая собой набор модулей для вычисления площади и периметра таких фигур, как: окружность, прямоугольник, квадрат и треугольник. 
Функции для разных фигур находятся в разных файлах, что обеспечивает удобство при многократном использовании кода. 


## 2. Описание функций с примерами вызова 

### [circle.py](circle.py)

#### area(r)
**Описание:** Вычисляет площадь окрудности по формуле S = pi\*r\*r\
**Параметры ввода:** 'r' - радиус окружности\
**Параметры вывода:** Площадь окружности (число) 

**Пример вызова функции:**
```python
from circle import area
print(area(6)) # 113.09733552923255
```
#### perimeter(r)
**Описание:** Вычисляет периметр окружности по формуле P = 2\*pi\*r\
**Параметры ввода:** 'r' - радиус окружности\
**Параметры вывода:** Периметр окружности (число)
 
**Пример вызова функции:**
```python
from circle import perimeter
print(perimetr(6)) # 37.69911184307752 
``` 
### [rectangle.py](rectanfle.py)
 
#### area(a, b)
**Описание:** Вычисляет площадь прямоугольника по формуле S = a*b\
**Параметры ввода:** 'a', 'b' - длины сторон прямоугольника\
**Параметры вывода:** Площадь прямоугольника (число)
 
**Пример вызова функции:**
```python
from rectangle area
print(area(2, 3)) # 6
```
#### perimeter(a, b)
**Описание:** Вычисляет периметр прямоугольника по формуле P = 2*(a + b)\
**Параметры ввода:** 'a', 'b' - длины сторон прямоугольника \
**Параметры вывода:** Периметр прямоугольника (число)

**Пример вызова функции:**
```python
from rectangle perimetr
print(perimetr(2, 3)) # 10
```
### [square.py](square.py)
 
#### area(a)
**Описание:** Вычисляет площадь квадрата по формуле S = a*a\
**Парметры ввода:** 'a' - длина стороны квадрата\
**Параметры вывода:** Площадь квадрата (число)
 
**Пример вызова функции:**
```python
from square area
print(area(3)) # 9
``` 
#### perimeter(a)
**Описание:** Вычисляет периметр квадрата по формуле P = 4*a\
**Параметры ввода:** 'a' - длина стороны квадрата \
**Параметры вывода:** Периметр квадрата (число)
 
**Пример вызова функции:**
```python
from square perimetr

```
### [triangle.py](triangle.py)
 
#### area(a, h)
**Описание:** Вычисляет площадь треугольника по формуле S = (a * h) / 2\
**Параметры ввода:** 'a' - длина стороны треугольника; 'h' - высота треугольника, опущенная на эту сторону\
**Параметры вывода:** Площадь треугольника (число)
 
**Пример вызова функции:**
```python
from triangle area
print(area(2, 3)) # 3
``` 
#### perimeter(a, b, c)
**Описание:** Вычисляет периметр треугольника по формуле P = (a + b + c)\
**Параметры ввода:** 'a', 'b', 'c' - длины сторон треугольника\
**Параметры вывода:** Периметр треугольника (число)
 
**Пример вызова функции:**
```python
from triangle perimeter
print(perimetr(1, 2, 3)) # 6
```
